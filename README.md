# Character Lab
Godot 4.4.1 • Windows x64 • Compatibility.

Envie o arquivo animado `character.glb` para a pasta `assets/`. O workflow Build Windows compila e publica `CharacterLab.exe` na release `windows-latest` após a compilação bem-sucedida.

Controles: WASD andar, Shift correr, Espaço pular, mouse câmera, scroll zoom, R reiniciar, Esc cursor.

O GLB preparado contém 21 ossos e seis animações: Idle, Walk, Run, Jump, Fall e Land. Teste visual na Godot ainda pendente.
