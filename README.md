# Character Lab
Projeto Godot 4.4.1, Windows x64, cena 3D de teste com personagem e câmera em terceira pessoa.

O arquivo `assets/character.glb` precisa ser enviado para completar o projeto. O workflow Build Windows exporta o executável e publica em Releases após uma compilação bem-sucedida.

WASD: andar; Shift: correr; Espaço: pular; mouse: câmera; scroll: zoom; R: reiniciar.

Animações procedurais e rig automático, ainda sem teste visual no Godot.
